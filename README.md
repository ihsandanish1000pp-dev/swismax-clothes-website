# SwisMax Clothes Website 👗

A modern and responsive clothing website showcasing stylish outfits and fashion collections.

## ✨ Features

- 👗 Clothing product gallery
- 🖼️ Product images and fashion videos
- 📱 Responsive design for mobile and desktop
- 🎨 Clean and user-friendly interface
- ⚡ Interactive functionality with JavaScript

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- WebP Images and MP4 Videos

- `index.html` — Website structure
- `style.css` — Website styling
- `script.js` — Interactive functionality
